I teach mathematics and build the tools I want in front of a class: small, fast, interactive pages that turn an abstract formula into something a student can grab and move.

This lab collects those experiments as they are made. Each simulation is a single HTML file, open source and free to use in a classroom — no account, no tracking, no server required.
