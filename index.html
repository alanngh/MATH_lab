Built while teaching, kept for the next class

I teach mathematics and build the tools I want in front of a room: small, fast pages that turn a formula into something a student can grab. The lab collects those experiments as they are made, Taylor polynomials today, whatever the course needs next.

  • Source repository

  • Each simulation is one HTML file with its own data and styling.
  • Folders group pages by course, and every folder becomes a class orb.
  • A small Python script rewrites this index whenever pages are added.
